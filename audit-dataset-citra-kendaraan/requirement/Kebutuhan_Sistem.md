# Kebutuhan Sistem

## Perangkat lunak
- Python 3.9+
- Pillow
- Sistem operasi Windows, Linux, atau macOS
- Editor kode atau terminal untuk menjalankan skrip

## Perangkat keras
- Komputer/laptop dengan RAM yang cukup untuk ukuran dataset
- Ruang penyimpanan sesuai ukuran dataset
- Koneksi internet hanya diperlukan untuk memperoleh dataset, bukan saat audit berjalan

## Masukan
Folder dataset dengan subfolder `mobil`, `sepeda_motor`, `bus`, dan `truk`.

## Keluaran
Laporan CSV audit, laporan file rusak, daftar duplikat, rekap kelas, dan manifest pembagian dataset.
