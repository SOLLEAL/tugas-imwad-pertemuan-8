# Kebutuhan Fungsional

1. Sistem membaca gambar dari empat folder kelas: mobil, sepeda_motor, bus, dan truk.
2. Sistem memeriksa keterbacaan gambar dan mencatat file yang gagal dibaca.
3. Sistem menghitung SHA-256 untuk gambar valid.
4. Sistem mengidentifikasi duplikat dalam kelas dan lintas kelas.
5. Sistem menghasilkan rekap audit per kelas dan laporan CSV.
6. Sistem membuat manifest pembagian train/validation/test secara deterministik.
